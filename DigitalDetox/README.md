# 戒断短视频 App (Digital Detox)

这是一个 Android 应用程序，旨在帮助用户控制短视频应用的使用时间。当用户连续使用抖音、快手、小红书或微信视频号超过 20 分钟时，应用会强制显示休息提醒。

## 功能特性

*   **智能监控**：利用 Android 无障碍服务 (AccessibilityService) 实时监控前台应用。
*   **覆盖提醒**：超时后通过悬浮窗权限 (SYSTEM_ALERT_WINDOW) 显示全屏不可取消的休息页面。
*   **支持应用**：
    *   抖音
    *   快手
    *   小红书
    *   微信 (尝试识别视频号)

## 如何构建和安装

由于云端环境缺少 Android SDK，请按照以下步骤在本地构建：

1.  **下载源码**：将本仓库下载到本地电脑。
2.  **打开项目**：使用 **Android Studio** (推荐 Hedgehog 2023.1.1 或更新版本) 打开 `DigitalDetox` 文件夹。
3.  **同步 Gradle**：等待 Android Studio 下载必要的依赖和构建工具。
4.  **运行**：连接你的 Android 手机，开启 USB 调试，点击 Android Studio 顶部的 "Run" (绿色的三角形按钮)。

## 使用说明

1.  安装并打开 App。
2.  点击 **"开启悬浮窗权限"**，在跳转的设置页中找到本应用并授权。
3.  点击 **"开启无障碍服务"**，在辅助功能设置中找到 **"戒断短视频监控服务"** 并开启。
4.  授权完成后，保持 App 在后台运行即可。

## 注意事项

*   为防止 App 被系统杀后台，建议在手机的电池设置中将本应用设为 **"无限制"** 或 **"允许后台高耗电"**。
*   微信视频号的检测依赖于类名识别，如果微信更新可能会失效，此时仅根据包名判断可能会误判聊天场景。
